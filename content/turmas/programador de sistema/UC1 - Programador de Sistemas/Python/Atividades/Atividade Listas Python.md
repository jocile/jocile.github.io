# Atividade Prática: Manipulação de Listas em Python

## Objetivo

Praticar a criação, manipulação, acesso e utilização de métodos da classe `list` em Python.

---

## Exercício 1: Acesso e Modificação de Dados

Crie um script Python que realize as seguintes ações:

1. Crie uma lista chamada `filmes` contendo os nomes de 5 filmes de sua preferência.
2. Adicione um novo filme ao final da lista utilizando o método apropriado.
3. Imprima na tela o nome do primeiro e do último filme da lista utilizando indexação (positiva e negativa).

## Exercício 2: Compreensão de Listas (List Comprehension)

Dada a lista de números abaixo:

`numeros = [1, 5, 8, 12, 15, 20, 25, 30, 33, 40]`

Utilizando a técnica de **Compreensão de Listas**, crie uma nova lista chamada `multiplos_de_cinco` que contenha apenas os números da lista original que são divisíveis por 5. Imprima a nova lista.

## Exercício 3: Métodos da Classe List

Crie um script que realize as seguintes operações com uma lista de nomes de alunos:

1. Defina uma lista com 5 nomes de alunos.
2. Ordene a lista em ordem alfabética.
3. Remova o segundo nome da lista (índice 1).
4. Imprima o tamanho final da lista utilizando a função `len()`.
5. Imprima a lista resultante.

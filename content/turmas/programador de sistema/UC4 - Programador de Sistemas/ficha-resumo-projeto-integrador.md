## 6. Checklist de Validação Técnica Pré-Palco

Antes de subir ao palco para a socialização dos resultados, confirme se todos os requisitos operacionais foram verificados pela equipe.

* **Servidor / Aplicação:** Sistema executando localmente sem erros no terminal.
* **Massa de Dados:** Banco de dados alimentado com registros de teste limpos para a demonstração.
* **Plano de Contingência (Backup):** Vídeo de 30 segundos da tela gravado para o caso de falha de conexão.
* **Repositório Público:** Código-fonte atualizado no GitHub com o arquivo `README.md` preenchido.
* **Apresentação Visual:** Slides validados e testados no projetor multimídia do auditório.

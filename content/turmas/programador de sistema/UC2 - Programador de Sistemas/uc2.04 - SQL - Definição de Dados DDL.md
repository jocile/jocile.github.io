> [!note] Fundamentos de SQL DDL
>
> - SQL (Structured Query Language): Linguagem estruturada de consulta para bancos de dados.
> - **DDL (Data Definition Language)**: Linguagem de definição de dados, utilizada para criar, modificar e alterar estruturas do banco de dados.
> - [SQL Introduction](https://www.w3schools.com/sql/sql_intro.asp) Comandos principais: `CREATE`, `ALTER`, `DROP`, `TRUNCATE`.
> - DDL é uma linguagem não-procedural que define o esquema estrutural do banco de dados.

> [!tip] Visão do Mundo do Trabalho
> O DBA (Database Administrator) define a arquitetura do SGBD e planeja as estruturas conforme as regras de negócio estabelecidas durante o levantamento de requisitos. DDD é responsabilidade fundamental da modelagem inicial do sistema.

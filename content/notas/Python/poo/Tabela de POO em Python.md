| Conceito | Descrição | Exemplo |
| -------------------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------------- |
| **O que é POO** | Paradigma de programação que abstrai problemas em objetos do mundo real. | Beber água usando um copo ou garrafa. |
| **Classes e objetos** | Classes definem características e comportamentos; objetos são instâncias de classes. | `class Cachorro:... cao_1 = Cachorro("chappie", "amarelo", False)` |
| **Construtores e destrutores** | Métodos especiais para inicializar e destruir instâncias de classes. | `class Cachorro: def __init__(self, nome, cor):...` |
| **Herança** | Capacidade de uma classe herdar características e comportamentos de outra. | `class B(A):...` |
| **Encapsulamento** | Agrupar dados e métodos que os manipulam, restringindo acesso direto. | `class Conta:... self._saldo = saldo` |
| **Polimorfismo** | Mesmo nome de função sendo usado para tipos diferentes. | `len("python")` e `len([10, 20, 30])` |
| **Variáveis de classe e de instância** | Variáveis compartilhadas entre objetos ou únicas para cada instância. | `class Estudante: escola = "Senac"...` |
| **Métodos de classe e estáticos** | Métodos ligados à classe, com ou sem acesso ao estado da classe. | Métodos de fábrica ou funções utilitárias. |
| **Classes abstratas** | Classes que definem contratos, não podem ser instanciadas. | Uso do módulo `abc` para definir classes abstratas. |
